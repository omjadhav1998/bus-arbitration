01 — FUNDAMENTALS

What is Bus Arbitration?

A bus is a shared communication pathway used by different components of a computer system.

When multiple devices request access to the bus at the same time, a conflict can occur.

Bus arbitration is the process of deciding which device gets permission to use the bus.

💡
Simple Example

Imagine one road with several vehicles. A traffic controller decides which vehicle can move first.

03 — ARBITRATION METHODS

How Can the Bus Be Controlled?

01

Centralized Arbitration

A central arbiter receives requests and decides which device gets control of the bus.

CENTRAL ARBITER
02

Daisy Chain

Grant signals pass through devices in a fixed order. The first requesting device receives the bus.

FIXED ORDER
03

Parallel Arbitration

Multiple request signals reach the arbiter simultaneously and priority determines the winner.

PRIORITY BASED
04

Distributed Arbitration

Devices participate in the arbitration process instead of depending completely on one central arbiter.

DISTRIBUTED
